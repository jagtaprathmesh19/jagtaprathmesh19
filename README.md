## Featured work

### [SmartOps Agent](https://github.com/jagtaprathmesh19/smartops-agent)

An AI-assisted cloud-operations system built around Google ADK and FastAPI. The code separates specialized compute, cost, knowledge, and monitoring agents from operational tools for GCP resource summaries, VM management, billing analysis, incident retrieval, and utilization analysis.

**Interesting because:** it combines agent orchestration with real cloud APIs, AlloyDB/pgvector semantic search, Vertex AI embeddings, Cloud Monitoring data, and an MCP server exposed over stdio.

`Python` `FastAPI` `Google ADK` `MCP` `GCP` `AlloyDB` `pgvector` `Vertex AI`

### [SKILL-Library](https://github.com/jagtaprathmesh19/SKILL-Library)

A structured library of reusable AI-agent skills and knowledge packs. It covers reasoning, validation, debugging, API design and security, backend architecture, AWS patterns, React components, UI design workflows, and agentic engineering.

**Interesting because:** the repository treats prompts and workflows as composable engineering assets, with consistent `SKILL.md` modules, supporting references, examples, and explicit model/tool metadata.

`Agentic engineering` `API design` `Backend architecture` `AWS` `React` `Security`

### [Kimi Code CLI](https://github.com/jagtaprathmesh19/kimi-cli)

A substantial Python codebase for a terminal-oriented AI developer tool, with CLI and web surfaces, MCP support, Agent Client Protocol integration, SDK/workspace packages, examples, and dedicated unit, AI, and end-to-end test areas.

**Interesting because:** the project demonstrates the engineering concerns behind extensible AI tooling—async execution, terminal UX, IDE integration, protocol adapters, packaging, type checking, linting, and multi-package development.

`Python 3.12+` `Typer` `FastAPI` `MCP` `ACP` `uv` `pytest` `WebSockets`

### [retail](https://github.com/jagtaprathmesh19/retail)

A current Spring Boot retail billing application with a Java 21/Maven foundation. Its build configuration includes Spring Web, Spring Data JPA, PostgreSQL, validation, OAuth2 client support, WebFlux, Jackson, AWS S3, and Docker configuration.

**Interesting because:** it shows a move toward enterprise-style backend development: persistence, validation, cloud storage, reactive HTTP support, and containerization in one service.

`Java 21` `Spring Boot` `JPA` `PostgreSQL` `AWS S3` `Docker` `Maven`

### [Spring-Boot-Projects](https://github.com/jagtaprathmesh19/Spring-Boot-Projects)

A collection of Spring MVC applications demonstrating REST APIs, Spring Security authentication and authorization, JPA persistence, MySQL, BCrypt password hashing, and Thymeleaf server-rendered interfaces.

**Interesting because:** it provides a clear foundation in secure CRUD-oriented web application design and Java backend patterns.

`Java` `Spring Boot` `Spring Security` `JPA` `MySQL` `Thymeleaf`

### [Optimizee.ai](https://github.com/jagtaprathmesh19/Optimizee.ai)

A Django application organized around authentication, user-facing workflows, donation-related functionality, media/static assets, and a refrigerator-storage optimization component. The repository also includes a YOLOv8 model artifact.

**Interesting because:** it connects web application development with a practical food-management problem and computer-vision experimentation.

`Python` `Django` `Authentication` `YOLOv8` `HTML/CSS`
